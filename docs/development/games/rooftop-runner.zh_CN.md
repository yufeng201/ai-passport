# 跃影疾行

离线横屏平台跑酷，实体键位：A 向左、B 向右、C 跳跃。跨越屋顶、收集发光奖励并到达终点。五关逐步加入高低差、尖刺与移动锯轮，屋顶检查点让失误后能快速继续。

## 开始游玩

1. 横向握持设备，无需配网。标题页短按 B 开始，A/C 选择已解锁关卡。
2. 按住 A 向左、按住 B 向右，地面松手立即停止。接近屋顶边缘时松开移动键，紧接着短按 C，沿原方向跳跃；站定后按 C 原地跳。
3. 空中保持跳跃方向，可用 A/B 调整；落地时未按方向键便停止水平移动，不会继续漂移。无需同时按两个键。
4. 长按 C 约 0.8 秒暂停，短按 B 继续；暂停时长按 A 返回标题。掉落或碰到障碍后自动回到最近检查点，保留本次已收集奖励与分数。
5. 到达终点后短按 B 进入下一关，第五关可重玩；结果页长按 B 返回标题。标题页长按 A 切换声音，自动保存解锁关卡、单关最高分与声音设置。

检查点位置与已收集奖励只保留在本次挑战中，返回标题后重新开始会重置本关。存储故障时解锁与纪录仅保留本次会话，不擦除已有数据。没有生命次数限制，可以反复尝试。

## 五关路线

每关 12 段固定屋顶，逐关缩窄平台、增加间距。第一段较宽，方便练习；第 1、4、7、10 段为检查点，检查点与终点均有旗帜提示。

| 关卡 | 地形 | 障碍 |
| --- | --- | --- |
| 清晨天台 | 等高屋顶，间距 30/36px | 无 |
| 错落街区 | 高低差最大 16px，间距 36/42px | 可见尖刺 |
| 尖角试炼 | 平台缩窄，间距 42/48px | 尖刺与更紧凑的起跳位置 |
| 流光机关 | 间距 48/54px | 移动锯轮 |
| 日出长廊 | 最窄平台，间距 54/60px | 移动锯轮与高低差组合 |

三键共用 ADC，每次只操作一个键。松开移动键后 350ms 内按下 C，会记住该移动方向；松开 C 触发一次固定跳跃，长按 C 暂停，松手不会补跳。离开边缘后有 100ms 的迟按起跳宽限；落地前 100ms 内短按 C 会缓冲一次跳跃，落地后接跳，不会空中二段跳。暂停与复位检查点会清除这些辅助状态。前两关用亮边与简短提示标示安全起跳区域；角色停下后保留朝向，加强描边和鞋尖对比。地面速度每 20ms 为 3px，初始跳跃速度为每步 -10px，重力每步增加 0.5px；等高跳跃约 780ms、水平距离 117px。等待不会蓄力，空中 C 不会二段跳。所有间距均能通过，不依赖技能。每枚奖励 100 分，抵达终点额外 500 分；掉落保留奖励位图，防止重复得分。

## 实现与验证

- `main/games/rooftop_runner/` 包含独立模型、中文文案、城市绘图、设备适配、构建清单与 Wasm 桥接。没有复用演示菜单或其他游戏的视觉布局。
- 模型 348 字节，无玩法动态分配。设备复用两个 320 × 40 RGB565 DMA 条带，共 50 KiB，不分配全屏缓冲，也不初始化 Wi-Fi/BLE/LVGL。浏览器帧缓冲不进入固件。
- 镜头留出前方视野，每模拟步最多移动 8px。镜头坐标不参与碰撞计算。建筑采用视差背景，各关独立天空配色，角色有跑步与围巾动画，奖励和旗帜清晰可辨。
- 20ms 定点模拟，每步四次微步进，检测向下穿越平台上表面与侧壁碰撞；落到平台下方不会被吸上屋顶。暂停冻结运动、障碍和反馈，清除按住状态，暂停键松手不会跳跃。
- 独立 NVS 命名空间 `rooftop_runner`。字体为 90 字 Noto Sans CJK SC 子集，Flash 字形记录 2,700 字节，许可 SIL OFL。保留 OTF 用于转换，不进入固件；字体工具依赖 Pillow 12.2.0、fonttools 4.62.1。

```bash
PASSPORT_GAME=rooftop_runner ./tools/validate.sh
python3 tools/games/rooftop_runner/build_preview.py
./tools/games/rooftop_runner/check.sh
python3 -m http.server 8770 --bind 127.0.0.1 --directory build/games/rooftop_runner/preview
```

固件构建前激活 ESP-IDF 5.5.3。浏览器键位：A/左箭头向左，B/右箭头向右，C/上箭头/空格跳跃，菜单 B/回车确认；屏幕按钮与实体键一致。失焦或取消指针时暂停，浏览器音效默认关闭，进度仅保留会话。`build/games/rooftop_runner/` 中 PNG 为实际代码绘图结果，不是实机截图。

主机测试覆盖五关共 100 次无掉落通关，改变起跳位置与 20～100ms 的 C 短按时间；另外完成五关反向返回路线，并验证镜头移动范围。回归覆盖松手停止、换向、站立/移动跳跃、无二段跳、高速落地、侧壁碰撞、禁止向上吸附、检查点恢复、奖励保留、暂停、陈旧时间戳、计时回绕、解锁和重玩。对 25 个场景比较五种条带高度与全屏渲染并检查内存边界。原生/Wasm 回放比较 2,000 步中的 21 个模型和 RGB565 检查点。硬件验收单独记录。
