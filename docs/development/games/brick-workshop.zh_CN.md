# 弹砖工坊

无需配网的横屏打砖块游戏。使用 A/C 移动挡板，接住光球，击碎五座工坊的彩砖。球落在挡板上的位置决定反弹方向；耐久砖、中央反弹支架与移动砖排逐关增加挑战。可选减速场提供额外的调整时间。

## 开始游玩

1. 横向握持设备，无需配网。标题页短按 B 开始；A/C 选择已解锁关卡。
2. 按住 A 向左移动，按住 C 向右移动，松手即停。短按 B 发球；用挡板接住光球，通过调整接触位置改变反弹方向。
3. 飞行中短按 B 使用三秒减速场，每关两次。每次只需操作一个按键，所有关卡均可不使用减速场通关。
4. 长按 B 约 0.8 秒暂停，短按 B 继续；暂停时长按 A 返回标题。漏接消耗三条生命之一，调整位置后短按 B 重新发球。
5. 通关后短按 B 进入下一关，失败后短按 B 重试，第五关结束可重玩。结果页长按 B 返回标题；标题页长按 A 切换声音。自动保存解锁关卡、单关最高分与声音设置，存储失败时仅保留本次会话进度。

## 五关挑战

| 关卡 | 布局 | 挑战 |
| --- | --- | --- |
| 彩窗初光 | 两排共 12 砖 | 熟悉挡板反弹方向 |
| 双层玻璃 | 三排共 18 砖 | 部分砖需两次命中，球速提升 |
| 反弹支架 | 18 砖与中央支架 | 判断额外反弹轨迹 |
| 流动彩窗 | 18 砖，砖排移动 | 跟踪横向移动，球速再次提升 |
| 光谱工坊 | 24 砖、移动砖排与支架 | 混合一至三次命中的彩砖 |

每次命中彩砖获得 50 分。漏接保留已消除的砖和分数，但结束当前减速场；重试会重置本关布局、分数、三条生命与两次减速。掉球后不会自动发球。连续六秒未命中砖时，下一次墙壁、天花板或挡板反弹会朝剩余彩砖调整方向，画面显示“弹道导向”；不会瞬移球，也不会改变支架的反弹。

## 实现与检查

独立目录 `main/games/brick_workshop/` 包含确定性玩法、中文文案、条带绘图、设备适配、构建清单和浏览器桥接。固件只包含选中的游戏，默认仍为狂飙骑手。游戏状态为 532 字节，无玩法动态分配。复用运行时的两个 320 × 40 RGB565 DMA 条带，共 50 KiB，不分配设备全屏缓冲，不初始化 Wi-Fi/BLE/LVGL。独立 NVS 命名空间为 `brick_workshop`。

中文字体使用 78 字的 Noto Sans CJK SC 子集，Flash 字形记录为 2,340 字节，许可 SIL OFL。保留 OTF 子集用于转换，不进入固件。字体工具依赖 Pillow 12.2.0 和 fonttools 4.62.1；扩展文案时使用 `generate_font.py --source <完整原字体.otf>`。

模拟步长为 20ms，每步进行八次定点微步进；挡板另外检查球扫过上表面的碰撞，避免高速穿板。移动砖重叠时向最近表面推出，每块砖每步最多扣一次生命。松手立即停止挡板，暂停冻结光球、砖排、减速与反馈，清除按住状态并抑制暂停键松手动作。忽略陈旧时间戳，测试覆盖计时回绕。

```bash
PASSPORT_GAME=brick_workshop ./tools/validate.sh
python3 tools/games/brick_workshop/build_preview.py
./tools/games/brick_workshop/check.sh
python3 -m http.server 8769 --bind 127.0.0.1 --directory build/games/brick_workshop/preview
```

构建固件前激活 ESP-IDF 5.5.3。浏览器支持 A/左、C/右、B/空格/回车与屏幕按钮；失焦或取消指针时暂停，音效初始关闭，浏览器进度仅保留本次会话。浏览器帧缓冲不进入设备固件。`build/games/brick_workshop/` 中渲染图来自实际绘图代码，属于代码预览而非实机截图。

测试使用 12 组种子、合法单键操作且不使用减速场，完成全部五关共 60 次通关。覆盖高速挡板碰撞、漏接、墙壁/彩砖/支架反弹、耐久砖、移动砖重叠、暂停、时间戳、解锁和重玩；对 25 个场景比较五种条带高度与全屏渲染一致性，并检查内存边界。原生/Wasm 回放比较 2,000 步中的 21 个状态和 RGB565 画面检查点。硬件验收单独记录。

## 当前五款游戏优化版

新增击碎六砖补充减速的补给循环及进度提示，持有上限三次；增加破砖粒子、补给音效、电子循环配乐和每关最高勋章保存。

1. 横向握持，无需配网。标题短 B 开始，A/C 选择已解锁关卡。
2. 按住 A/C 左右移动挡板，短 B 发球；接住下落光球，把它弹向彩砖，漏接会消耗生命。
3. 飞行中短 B 使用减速场，帮助接球；每击碎六块砖补充一次，最多持有三次，观察补给进度提示。
4. 长 B 暂停，短 B 继续；暂停长 A 返回标题。标题长 A 切换声音。
5. 清空彩砖后短 B 下一关，失败短 B 重试，第五关可重玩；解锁、最高分与每关勋章自动保存。

当前固件身份与验证边界见[批次报告](quality-upgrade.zh_CN.md)。本文之前的构建、实机记录仅适用于对应历史版本。
