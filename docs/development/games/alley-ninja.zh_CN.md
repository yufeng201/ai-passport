# 夜巷忍者

横屏离线动作游戏，围绕读招、判断方向和防守反击展开。短按 A/C 左右斩击，按住 B 格挡，松开 B 后再反击。敌人依次靠近，不要求同时按两个键。五关逐步从单侧敌人进入双侧、护甲、变速节奏与换边首领。

## 上手

1. 开机后横握设备，无需配网。标题页短按 B 开始，A/C 选择已解锁关卡。
2. 敌人靠近时短按 A 左斩、C 右斩。距离太远或方向错误会落空；感叹号和缩短的红条表示敌人即将出招。
3. 按住 B 格挡；在命中前最后 160 ms 内开始格挡，可获得完美格挡奖励。普通格挡同样打开反击窗口：松开 B，再按对应方向斩击。护甲敌人需要先格挡才能击破。
4. 留意体力条，持续格挡消耗体力，松手恢复；耗尽后短暂破防。长按 C 约 0.8 秒暂停，短按 B 继续，暂停时长按 A 返回标题。暂停会清除格挡并冻结战场，松开暂停键不会补一次斩击。
5. 失败后短按 B 重试；前四关通关后短按 B 晋级，第五关可重玩。结算页长按 B 返回标题，标题页长按 A 切换声音。解锁关卡、最佳单关成绩和声音设置会保存；存储失败时只保留本次运行记录。

每次只操作一个键。斩击在松手时立即触发，不等待双击窗口，有 240 ms 冷却；持续按住方向键不会连斩。体力耗尽后持续按住 B 不会自动恢复格挡，需松手恢复体力后重新按下。

## 五关与攻防

| 关卡 | 敌人 | 难度变化 |
| --- | --- | --- |
| 初入夜巷 | 右侧五名轻型敌人 | 1.2 秒出招预警 |
| 两侧来袭 | 六名左右交替敌人 | 1.1 秒预警 |
| 铁甲试炼 | 七名交替敌人 | 两点耐久护甲，先格挡再反击 |
| 错拍街区 | 八名敌人 | 更快接近与 0.8／1.0／1.2 秒不同预警 |
| 影卫决战 | 四名护卫与首领 | 首领五点耐久，每轮出招后换边接近 |

同时只有一名敌人出招。普通格挡消耗 24 体力，完美格挡消耗八点；持续格挡每秒消耗 25 点，松手每秒恢复 50 点。开始格挡至少需要 24 点，体力耗尽会有 800 ms 破防，期间不能斩击或格挡。格挡后护甲暴露一秒，敌人恢复 1.1 秒，留出松开 B、换键反击的时间。斩击范围为离角色 58 px。轻型／护甲敌人为 100／200 分，首领为 1,000 分；连续完美格挡额外获得当前连击数乘 20 分（连击最多 99），成绩上限为 1,000,000，保证长时间游玩仍符合存档格式。失败／重试仅重置本关战斗，保留解锁与最佳成绩。

## 实现与验证

- `main/games/alley_ninja/`：确定性纯攻防模型、中文文案、独立霓虹街巷绘图、设备入口、构建清单和浏览器桥接。
- `main/games/common/` 复用运行循环与音效，只有选中游戏进入固件，默认仍为狂飙骑手。
- 状态为 188 字节，战斗不动态分配内存。设备使用两块 320 × 40 RGB565 缓冲，共 50 KiB，不分配整屏缓冲，不初始化 Wi-Fi／BLE／LVGL。
- 字库为 96 个 12 px Noto Sans CJK SC 字形，Flash 记录 3,090 字节，SIL OFL。OTF 保留用于转换，不嵌入固件。生成／检查：`python3 tools/games/alley_ninja/generate_font.py [--check]`；新增字符需通过 `--source` 提供完整源字库。
- 独立 NVS 命名空间 `alley_ninja`，沿用最佳／解锁／静音三字段进度格式。存储错误只降级为本次记录，不擦除已有数据。
- 固定 20 ms 模拟步长，长按判定使用原始输入时间，积压时间不会误当计时回绕。暂停冻结敌人倒计时、体力、冷却与反馈。


主机测试使用 16 组种子、五关和普通／完美两种格挡，完成 160 个关卡流程，每关均可用普通格挡通关。检查距离／方向、护甲、冷却、体力耗尽与恢复、暂停、长按切页、积压时间、计时回绕、保留进度，以及 25 个画面的五种分块尺寸。原生 C／Wasm 回放 2,000 步，比较 21 个状态与 RGB565 画面检查点。完整门禁后分别记录构建、设备结果与未验证项目。

## 当前五款游戏优化版

新增连续精准格挡后的重击反击窗口、连段提示与火花；增加三目标勋章保存、夜巷循环配乐及精准/格挡音色；错误方向不会消耗重击，受伤取消窗口。

1. 横向握持，无需配网。标题短 B 开始，A/C 选择已解锁关卡。
2. 短 A 向左斩击、短 C 向右斩击；敌人靠近后，按住 B 格挡，看准出招时机再松 B 反击。装甲敌人需先格挡使其露出破绽。
3. 连续精准格挡可获得短暂重击窗口；松 B 后朝敌人的方向斩击。留意体力，松开格挡可恢复。
4. 长 C 暂停，短 B 继续；暂停长 A 返回标题。标题长 A 切换声音。
5. 通关短 B 下一关，失败短 B 重试；解锁、最高分与每关最高勋章自动保存。

当前固件身份与验证边界见[批次报告](quality-upgrade.zh_CN.md)。本文之前的构建、实机记录仅适用于对应历史版本。
