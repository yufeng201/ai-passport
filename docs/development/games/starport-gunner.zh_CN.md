# 星港炮手

横屏离线防守射击游戏。A/C 调整固定炮台，松开方向键后炮口保持角度，再用 B 射击；不需要同时操作两个按键。五关逐步加入巡航敌舰、护甲、交叉航线和旗舰。拦截来袭导弹，守住星港的三格护盾。

## 上手

1. 开机后横握设备，无需配网。标题页短按 B 开始；A/C 选择已解锁关卡。
2. 短按 A/C 将炮口向左／右移动一档。短按 B 松手发射普通弹；穿透炮可用时，按住 B 至少半秒，松开发射。蓄力最多 1.2 秒，不会自动开火。
3. 十字和虚线会提前标出敌弹，随后导弹向下飞行。炮弹可以拦截导弹或击落敌舰；金色血条表示护甲舰和旗舰的剩余耐久。星港有三格护盾，穿透炮冷却 2.4 秒期间仍可发射普通弹。
4. 长按 C 约 0.8 秒暂停，松手不会补一次转向。短按 B 继续；暂停时长按 A 返回标题。暂停取消未释放的蓄力，并冻结战场。
5. 失败后短按 B 重试；前四关通关后短按 B 晋级，第五关可重玩。结算页长按 B 返回标题。标题页长按 A 切换声音。固件保存已解锁关卡、最佳单关成绩和声音设置；存储失败时仍可游玩，但记录仅保留在本次运行中。

每次只操作一个按键。切换页面后先松开旧键，再开始新操作。持续按住方向键不会反复转向；穿透炮冷却时长按 B 松手仍发普通弹，蓄力文案明确显示当前可用弹种。

## 五关

| 关卡 | 敌舰 | 变化 |
| --- | --- | --- |
| 静谧航道 | 六艘轻型舰 | 直线进入，固定位置开火 |
| 巡航来袭 | 七艘轻型舰 | 缓慢横移巡航 |
| 装甲突围 | 八艘混合舰 | 加入两次普通命中才能击破的护甲 |
| 交错星轨 | 九艘混合舰 | 相反方向的较快巡航与三次命中护甲 |
| 旗舰决战 | 四艘护航舰与一艘旗舰 | 旗舰 16 点耐久，更频繁攻击 |

同时最多三艘敌舰。敌弹先预警 800 ms，再以 100 px/s 下落。任一位置漏过的导弹都会伤害星港；受击后有 700 ms 保护，避免多个同时落地瞬间扣光护盾。普通弹造成一点伤害，穿透炮造成三点伤害、最多命中三个目标，同一炮弹重叠同一舰体不会重复伤害。轻型舰／护甲舰为 100／200 分，旗舰为 1,200 分，拦截导弹为 25 分。击落本关所有敌舰且护盾尚存即通关。

## 架构与资源

- `main/games/starport_gunner/`：确定性模型、独立中文文案与分块绘图、设备入口、构建清单和浏览器桥接。
- 当前固件复用 `main/games/common/game_runtime.c` 与音效，不链接其他游戏模型。
- 状态为 1,312 字节；固定对象池含六个舰槽、24 枚玩家炮弹、12 枚敌弹。逻辑更新不动态分配内存。
- 两块 320 × 40 RGB565 缓冲共 50 KiB，无设备整屏缓冲，不初始化 Wi-Fi、BLE 或 LVGL。
- 字体为 76 个 12 px 中文字形，Flash 记录 2,280 字节，Noto Sans CJK SC，SIL OFL 许可。OTF 子集不链接进固件。生成／检查：`python3 tools/games/starport_gunner/generate_font.py [--check]`，新增字符需使用 `--source` 提供完整源字库。
- 固定 20 ms 物理步长；炮弹使用扫掠线段与命中矩形，防止高速穿透目标。长短按依据原始事件时间戳，过期模拟时间不会误当计时回绕。暂停与长按松手遵守共享输入所有者规则。
- 独立 NVS 命名空间为 `starport_gunner`，共享三字段进度格式和存储降级策略。完整固件替换可能重置记录。

## 构建与浏览器试玩

激活 ESP-IDF 5.5.3 后：

```bash
PASSPORT_GAME=starport_gunner ./tools/validate.sh
python3 tools/games/starport_gunner/build_preview.py
./tools/games/starport_gunner/check.sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory build/games/starport_gunner/preview
```

访问 `http://127.0.0.1:8767`。A／左方向键、C／右方向键调整炮口；B／空格／回车射击或蓄力。页面按钮支持相同按下／松开操作。失焦或输入取消会暂停。浏览器音效独立控制，默认关闭，网页进度仅保留本次运行。试玩使用同一 C 模型和 RGB565 绘图；原生／Wasm 一致性不能代表浏览器交互或硬件验证。

`tests/games/test_starport_gunner.c` 使用八组种子完成 40 关模拟；模拟玩家只使用单键边沿，瞄准切换间隔 100 ms。还检查蓄力上限、冷却、暂停、积压输入、计时回绕、护盾伤害、敌弹拦截、扫掠碰撞、穿透单次命中、重试进度，以及 25 个画面的五种分块尺寸。原生 C／Wasm 回放 2,000 步，比较 21 个状态和完整 RGB565 画面检查点。`build/games/starport_gunner/` 的图片是实际绘图代码的主机渲染，不是实机截图。
