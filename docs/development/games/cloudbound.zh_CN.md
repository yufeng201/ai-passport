# 云间一跃

横屏离线蓄力跳跃游戏。按住中间的 B 键积蓄力度，松手跃向下一座浮岛；落在中央获得精准连击，踩边仍可继续。五关从晨雾、晴空、晚霞到星夜和极光，逐步增加距离变化、缩窄落脚平台，并引入高低台阶。每关完成 12 次落地即可晋级。

## 上手

1. 开机后横握设备，无需配网。标题页短按 B 开始；A/C 可选择已解锁关卡。
2. 站在平台上时按住 B 蓄力，松开跳跃。力度达到上限后保持，不会自动起跳。第一关显示轨迹和落点辅助，后续关卡需要自己估距。
3. 飞行和落地镜头移动期间等待角色站稳，再重新按住 B。长按 C 约 0.8 秒暂停，短按 B 继续；暂停后长按 A 返回标题。
4. 通关后短按 B 下一关，失败后短按 B 重试当前关。结算页长按 B 返回标题，标题页长按 A 切换声音。固件保存解锁进度、最佳单关成绩和声音设置；存储不可用时仍可游玩，但记录只保留到本次关机。

按键每次只操作一个。开始、继续、重试等操作按松开触发，不等待双击判定；长按完成后松手不会额外触发短按。暂停取消未释放的蓄力，继续时不会误跳；已经起跳时暂停保留轨迹和位置。

## 五关与规则

| 关卡 | 场景 | 变化 |
| --- | --- | --- |
| 晨雾初行 | 蓝色晨雾、云海和日光 | 宽平台、较小距离变化、完整轨迹辅助 |
| 晴空漫步 | 青蓝晴空 | 加大距离变化，取消轨迹辅助 |
| 晚霞窄桥 | 粉紫晚霞与金色落日 | 进一步缩窄平台 |
| 星夜高台 | 深蓝星夜与月牙 | 加入上下台阶 |
| 极光之旅 | 青绿极光与星空 | 最窄平台与高低差组合 |

成功落地获得 100 分；中央 8 px 范围内的精准落地增加连击，每次额外获得当前连击数乘 20 分。普通落地重置连击。失败只重试当前关，不清空已解锁关卡和最佳成绩。全部通关后可重试第五关或返回标题选关。

蓄力在 100～1,200 ms 内映射到确定的水平距离；飞行用固定 600 ms 弧线，平台不会随机移动，也没有隐藏风力。每次起跳后需要重新按下，飞行中的操作不会缓存成下一次跳跃。落地后镜头平滑移动 300 ms。生成器使用同一套落点函数，平台宽度和距离范围保留至少 150 ms 的成功蓄力窗口。

## 目录与构建

- `main/games/cloudbound/`：独立模型、中文文案、RGB565 分块绘图、设备入口及浏览器桥接。
- `main/games/common/`：设备运行循环和合成音效；纯玩法不依赖 BSP 或 ESP-IDF。
- `tools/games/cloudbound/`：字体覆盖、浏览器构建、一致性检查和离线画面生成。
- `tests/games/test_cloudbound.c`：输入时序、计时回绕、可达性、64 组完整五关模拟、暂停／重试与绘图边界。

激活 ESP-IDF 5.5.3 后，以显式游戏名构建完整固件：

```bash
PASSPORT_GAME=cloudbound ./tools/validate.sh
```

默认游戏仍为 `road_rage`。合并固件和匹配 ELF 保存于 `build/firmware/<sha256>/`，刷写应使用该次归档中的完整合并文件；不同游戏的构建会更新公共交付文件，不能仅按文件名猜当前内容。USB 刷写与社区提交分别需要对应授权。

## 浏览器试玩

```bash
python3 tools/games/cloudbound/build_preview.py
./tools/games/cloudbound/check.sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory build/games/cloudbound/preview
```

打开[本地试玩](http://127.0.0.1:8766)。B／空格／回车用于蓄力，A／左方向键和 C／右方向键对应外侧实体键。也可按住页面按钮。浏览器失焦或取消指针会暂停并清除旧输入，音效默认关闭。浏览器使用相同 C 模型与绘图代码，刷新会清除该网页的进度；固件保存使用设备存储。macOS 工具链需要时，可为本次检查设置匹配的 `SDKROOT`，不改系统默认配置。

## 资源与验收

模型为 164 字节，设备使用两块 320 × 40 RGB565 DMA 缓冲，共 50 KiB；无整屏设备缓冲，不初始化 LVGL、Wi-Fi 或 BLE。中文包含 88 个 12 px 字形，Flash 字形记录 2,640 字节；OTF 子集仅用于字体生成，不链接到固件。字体使用 Noto Sans CJK SC 的 SIL OFL 许可，正常构建不需要字体转换依赖。

按键回调只入队，游戏所有者处理逻辑、存储和显示，音频使用独立任务。输入队列溢出会暂停，显示传输失败后停止并保留在途 DMA 内存，避免继续写入。存储初始化或写入失败降级为本次运行的进度，不自动擦除 NVS；声音不可用时静音游玩。

主机检查覆盖 320 个完整关卡流程、3,840 次落地及各平台的有效蓄力窗口；图像检查覆盖五关的标题、游戏、暂停、成功和失败状态。原生 C 与 Wasm 比较相同回放的状态哈希和 RGB565 画面，不能代替浏览器操作或实体设备验证。帧率目标至少 25 FPS，内部可用堆目标至少 30 KiB、最大连续块至少 16 KiB；实际方向、中文可读性、手感、声音、断电记录与忙碌场景性能需要真机确认。
