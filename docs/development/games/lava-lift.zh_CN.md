# 熔岩升梯

站在升降平台上逃离不断上涨的岩浆。第一键左移平台，第二键右移平台，第三键跳跃。按住方向键持续移动，角色在空中也会跟随平台，无需同时按键。岩浆和平台自动上升，通过岩壁滚动表现攀升。

## 如何游玩

按 C 开始。让整个平台穿过岩壁上金色边缘的空隙。跳过靠近的岩浆小怪，下降时踩中小怪可将其消灭。撞岩壁或被小怪碰到会扣除一格生命，并获得 1.4 秒无敌时间。共有三格生命，到达 1200 高度（约 60 秒）即可逃生。失败或获胜后按 C 重玩。设备通过共享运行时保存最高高度。

设备画面使用英文标签和图标，浏览器操作说明使用中文。输入取消或超过 200 毫秒的模拟间隔会暂停，按 C 继续。浏览器失去焦点立即清除按键状态并暂停。三个游戏按键没有手动暂停快捷操作。

## 构建和试玩

显式选择此游戏，仓库默认游戏保持原有设置：

```bash
PASSPORT_GAME=lava_lift ./tools/validate.sh
python3 tools/games/lava_lift/build_preview.py
./tools/games/lava_lift/check.sh
python3 -m http.server 8771 --bind 127.0.0.1 --directory build/games/lava_lift/preview
```

完整验证前需激活 ESP-IDF 5.5.3。试玩编译使用已有 Wasm 工具链。浏览器与固件运行相同的 C 游戏逻辑和渲染器，方向键移动，空格跳跃。浏览器记录仅保留本次会话。设备使用共享运行时的两块 DMA 条带绘制，不分配全屏缓冲，不启动 LVGL。音频失败时可静音游玩。英文文字使用已有的授权 Cloudbound Noto 字形资源。

## 验收

主机测试覆盖移动边界、跳跃时序、岩壁伤害、无敌时间、小怪攻击与踩踏、暂停、重玩、获胜、更新节奏，以及条带与全屏渲染一致性。原生与 Wasm 回放在 21 个检查点比较状态及画面哈希。实际屏幕方向、实体按键顺序、响应速度、声音和全程难度仍需真机测试。编译和浏览器测试不代表硬件验收。
